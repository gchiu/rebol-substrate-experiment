Language at a glance

AreaContract
ValuesOne tagged cell: integer, none, word forms, block, context, closure, native, RAW, user, string, BOUND or SIN!.
EvaluationPrefix, fixed-arity, eager left-to-right. No infix operators, parentheses or commas. Calls consume following complete expressions.
WordsDynamic lookup through the lexical context chain. A set-word updates the nearest existing binding or creates a local. A get-word looks up without invoking.
BlocksData until evaluated. do runs in the current context; values returns all results; reduce builds a managed block.
FunctionsLexical closures. Literal bodies capture their own scope; computed bodies keep their origin. A bare dependent block may not escape its activation.
FailuresSIN! is a value; raise propagates; judge catches. Machine fail-stops cannot be judged.
StringsImmutable byte sequences. Content equality is s/= or str-eq; = is identity.
TasksCooperative, deterministic library tasks: spawn, yield, run-tasks. No pre-emption.
Limits64K reference machine, 7,232-cell managed heap, 256 global bindings, 16 per function, ~84 nested calls. Capacities are implementation limits, not semantics.

Provenance: what is what

Glon is layered. Do not treat a library word or a host operation as part of the frozen substrate.

LayerExamplesMeaning
Frozen S1LIT DUP DROP @ ! 0BRANCH HOSTThe seven-primitive substrate. Not ordinary Glon vocabulary; reachable through masm/raw.
R0 natives over S1 HOST+ - * / = < > <= >= printOrdinary Glon words implemented by the evaluator over frozen host arithmetic/comparison/output.
Evaluator mechanicsfunc return either do invoke reduce values, SIN! wordsRuntime behaviour emitted above S1; not S1 primitives.
Glon librariesmk-string get lambda does block-at select case parse s/+ s/print, tasksOrdinary Glon source loaded per session. They are not core natives.
Host-specificglon_*, host_*, route/event dispatch, files/network/DOMHost boundary and application policy, not portable language semantics.

Implemented versus unresolved

VERIFIED Reader grammar, all 20 productions, rail diagrams, frozen-S1 guard and the documented language laws/tests.

UNRESOLVED The following are explicitly not defined or tested as language contracts. Do not guess them from an accident in the runtime:

  • non-integer arithmetic or print; division/modulo by zero;
  • non-block do/either; missing or extra call arguments;
  • malformed func specs (non-block, duplicate or overfull parameters);
  • return with no following expression;
  • values zero/multi-result forms and first-result collapse at argument position;
  • token-truncation collisions, malformed empty masm blocks and some host/comment edge cases.

See the verification report §7 and the language specification §11.3 for the prioritised list.
