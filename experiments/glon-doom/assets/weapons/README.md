# G5r weapon reference assets

Source ZIP: `/mnt/c/Users/anon_/Downloads/glon-avp-weapons-reference-pack.zip`
Supplied README: `reference/README.md`.

All four references are 1672×941 full-scene corridor illustrations with baked
backgrounds, not transparent sprites or atlases:

| reference | composition |
|---|---|
| `pulse-rifle-reference.png` | rifle and gloved/bare hand, lower centre-right, baked green `60` |
| `shotgun-reference.png` | pump shotgun, lower right, one visible hand |
| `pistol-reference.png` | compact pistol, centred, gloved hand |
| `flamethrower-reference.png` | fuel tank and long nozzle, lower right, gloved hands |

The corridor, lighting, props and smoke in those files are not usable in-game.
Only the pulse rifle has been converted; the other three remain references.

## Pulse-rifle conversion

`pulse-rifle-hands.png` is a hand-masked 768×406 transparent crop from
`pulse-rifle-reference.png`. The silhouette was traced manually to remove the
corridor, including the carry-handle opening. The baked `60` was blanked and an
inner bezel retained. Runtime code draws Glon's ammunition value into that panel
using a seven-segment-style green display.

Limitations:

- one visible hand, as in the reference; no separately modelled support hand
- manual mask, so fine edge quality is below a purpose-made alpha asset
- static first-person pose; no recoil, muzzle flash, reload, firing or switching
- no claim that the reference is a game-ready atlas

`weapon_sprites.h` is generated by `tools/convert_g5r_weapon.py`.
