Glon LaTeX

Two vocabularies on one small runtime. In Glon, + 1 2 is the number 3, while l/+ 1 2 is the notation 1+2. Both are ordinary words, evaluated by the same Glon interpreter running in your browser as WebAssembly. Everything on this page is live: edit any example and press Run.

The mathematical samples are from Christopher Ross-Gill's Rebol LaTeX Equation Notation Generator (math.test.reb). Each of his expressions is shown beside its Glon equivalent.

Numbers and notation

The same expression shape, read by two vocabularies. The bare words compute; the qualified l/ words describe. Numeric words inside a LaTeX expression are evaluated first, and their results become part of the notation.

Chris Ross-Gill's samples

All seventeen figures from the seven latex-math/render calls in math.test.reb. Rebol's infix operators run strictly left to right, and Chris's generator uses Rebol's ( ) and [ ] to group. In Glon, every call takes a fixed number of arguments, so the nesting of calls is the expression tree, and the l/ words add only the brackets that the grouping needs. Where the original's typesetting loses its grouping, a note says so.

Infix input

Type mathematics the usual way. A small JavaScript front end (infix.js) translates it into Glon prefix source, and that Glon runs on the same runtime and the same l/ words as every example above. The translator only rewrites notation: it evaluates nothing and builds no LaTeX.

So -a*b is (−a)·b, -a^2 is −(a²), and (-a)^2 keeps
    its grouping. A name of several letters is one variable (dx); write
    a b for a product, and x (y + 1), with a space, because
    x(…) is read as a function call.

    
Implicit multiplication after division. Implicit multiplication binds more
    tightly than /, so 1/2x means 1/(2x). Readers disagree about
    this, so use parentheses: (1/2)x for one half of x, and 1/(2x)
    to make the other reading explicit.

    
Functions: sqrt(x), root(n, x), ln(x),
    sum(lower, upper, body), prod(…), int(…)
