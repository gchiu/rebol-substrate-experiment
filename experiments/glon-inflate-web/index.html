Glon Inflate

DEFLATE decompression using Glon's original seven-primitive execution core.

Glon is an experimental compact execution language designed for AI-generated software. This demonstration runs a DEFLATE decompressor using the original seven-primitive S1 execution core.

DEFLATE is the compression algorithm inside ZIP and gzip. Raw DEFLATE is the codec itself; zlib and gzip add container headers and checksums around it. This page strips zlib/gzip container framing in JavaScript, then sends the DEFLATE payload to the actual Glon decoder. No JavaScript decompressor is used.

The browser adapter accepts compressed bytes, validates the container, and generates a Glon driver containing those bytes. This demonstration accepts at most 3,000 compressed bytes (the runtime source buffer is 16 KiB).

Demonstration limits

  • Maximum compressed input: 3,000 bytes.
  • LZ77 history window: 768 bytes.
  • Not all valid DEFLATE streams are supported by this demonstration; a stream needing a longer back-reference window reports a Glon window error.

These are limits of this browser demonstration and its 64K Glon runtime, not a JavaScript fallback. The seven-primitive S1 core and Glon decoder are unchanged.

Execution path

    

      
Execution core
Original S1: seven primitives, LIT DUP DROP @ ! 0BRANCH HOST. No experimental native acceleration primitives.

      
Decoder
inflate.glon, the existing streaming RFC 1951 implementation, with F2's bounded Huffman code-length buffer.

      
Browser runtime
glon.wasm: the standard seven-primitive shop runtime. DEFLATE runs in WebAssembly, not JavaScript.

      
Conformance baseline
Repository verification: 480/480 differential runs and 44/44 unit tests. These are repository results, not tests executed by each browser interaction.

      
Input handling
Base64, hexadecimal, local files and samples. zlib/gzip wrapping is removed by the host; the DEFLATE codec is always Glon.

    

    
This is a local demonstration, not a deployed service. Source: experiments/glon-deflate.
