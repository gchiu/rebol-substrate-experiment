Glon Parse

Rebol 2-style PARSE on the original seven-primitive S1 execution core.

Glon PARSE executes parsing rules in Glon on a seven-primitive WebAssembly runtime. JavaScript provides the browser interface but does not implement the parsing algorithms.

This page runs the existing Glon PARSE engine—the same rule interpreter tested against a genuine REBOL/Core 2.7.8 oracle—in WebAssembly on the frozen S1-7 runtime. The parser, search, repetition, character-set matching and capture logic run in Glon.

Rules below use a small textual PARSE syntax that the browser lowers into encoded Glon data before execution. It is a tested subset, not a claim of full Rebol 2 PARSE compatibility.

Rules are tokenised and lowered into the existing encoded Glon data, then executed by the Glon parser. The generated driver is limited to 16 KiB by the runtime source buffer; inputs are limited to 2,000 UTF-8 bytes.

Result

Textual rule syntax

Rules are read by a small front end and lowered into the existing encoded Glon data; matching always runs in Glon. The supported subset is:

SyntaxMeaning
"literal"literal string; backslash escapes \n, \r, \t, \xHH, \", \\; case-insensitive by default
[ rule … ]sequence; | separates ordered alternatives
some rule, any rule, opt rulerepetition
n rule, min max ruleexact or bounded repetition
skip, to "target", thru "target", endnavigation and non-consuming end test
charset "a-z0-9_"character set; ranges use lo-hi; matching is case-sensitive
copy name rulecapture the source slice
nonezero-length success, no consumption
namenamed rule from the definitions area

Named definitions use one line per rule, e.g. digits: [ some digit ], with the top rule in the field above. Strings may contain [, ], | and comments. Unsupported operators are rejected with an error.

Execution path

    

      
Core
Frozen S1-7: LIT DUP DROP @ ! 0BRANCH HOST. Not S1-12.

      
Runtime
Standard glon.wasm (seven-primitive shop runtime) built from the current runtime sources.

      
Parser
The existing parse.glon from experiments/glon-parse-r2/; captures are displayed after the parse. No host parser or precomputed results.

      
Verification
Repository baseline: 151/151 Glon checks and 127 Rebol 2 oracle probes. Those are repository results, not tests performed by each click.
