Each task has a specification (<task>.md), A/B/C artifacts, and an independent
reference implementation in b5_main.c. Reference code is not included in the
generation prompts. Negative constants are represented as subtraction from
zero so all three representations lower to identical code.

LLM TRIALS

Unperformed. The generation harness is in generation/ with:
  - 12 task specifications;
  - equivalent A/B/C prompts;
  - run_trial.sh with one initial attempt and up to three repairs;
  - run_suite.sh randomising task/representation order;
  - trial-log-schema.md;
  - results.md recording that no trial was run.

The harness accepts B/C as whitespace-separated 32-bit hex words and converts
them to the B4 binary word streams; this is an authoring interface, not a
change to B4. No claim is made about first-attempt correctness, repair success,
tokens, cost, elapsed development time or LLM ease for any representation.

LIMITATIONS

- No genuine LLM sessions were orchestrated; no productivity measurement.
- The 12-task suite is small and uses a restricted integer subset.
- B/C artifacts were prepared by the B5 fixture generator; authoring effort is
  not included in source-processing timings.
- Reference execution is identical because the fixtures lower to identical
  code; no generated-program code-quality difference is measured.
- Negative inputs are represented by subtraction from zero; edge coverage is
  limited to the listed tasks.
