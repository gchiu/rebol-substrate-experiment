# Glon Shop — G1E (repeated interactive composition)

G1A proved the persistent browser-hosted machine; G1B layered a composable view
dialect; G1C added generic token events; G1D added value-bearing events; G1E
combines them into a dynamically generated family of interactive controls. See
`../../GLON-SHOP-G1E.md` (and `G1A.md`/`G1B.md`/`G1C.md`/`G1D.md`).

| file | role |
|---|---|
| `app.html` | the bundled page (generated by `build.py`) |
| `bundle.glon` | the combined GLON source (generated by `build.py`; used by `node_test.js`) |
| `shop.glon` | the authoritative application (state, catalog, views, routes, events, router) |
| `g1b.glon` | the view-dialect library (emitters + view terms, incl. `button`/`value-button`/`input`) |
| `fragments/*.html` | G1A's HTML fragments (superseded by the view dialect; retained for reference) |
| `host.js` | the handwritten JS host bridge (DOM writes + route/event forwarding, incl. values) |
| `build.py` | expands string literals to byte-lists; bundles `app.html` + `bundle.glon` |
| `glon.wasm` | the WASM runtime (built by `make wasm-g1a`) |
| `node_test.js` | headless verification |

## Build

```
emcc            # Emscripten >= 3.1 (tested 3.1.74)
node            # for the headless test
make wasm-g1a   # builds glon.wasm + bundles app.html
```

## Launch

```
python3 -m http.server 8000
# open http://localhost:8000/demo/shop/app.html
```

## Manual acceptance

```
Open app → see "Glon Shop"
click "View products" → Products page, "Products page visits: 1", "Cart: 0"
click "Add" next to Tea → "Cart: 1", "Last added: Tea"
click "Add" next to Rice → "Cart: 2", "Last added: Rice"
click "Add" next to Tea → "Cart: 3", "Last added: Tea"
click "Back home" → Home
click "View products" → visits 2, cart 3, "Last added: Tea" (persisted)
```

No page reload; the persistent Glon machine handles routes and value-bearing
events, and JavaScript never interprets `add-product` or a product name.
