# Glon Shop — G1B (minimal persistent-SPA dialect)

G1A proved the persistent browser-hosted Glon/WASM machine. G1B layers a small
view dialect (`heading` / `text` / `list` / `link`) over it, so the shop reads
as a Rebol application instead of HTML templates. See `../../GLON-SHOP-G1B.md`.

| file | role |
|---|---|
| `app.html` | the bundled page (generated by `build.py`) |
| `bundle.glon` | the combined GLON source (generated by `build.py`; used by `node_test.js`) |
| `shop.glon` | the authoritative application (state, catalog, views, routes, router) |
| `g1b.glon` | the view-dialect library (emitters + view terms) |
| `fragments/*.html` | G1A's HTML fragments (superseded by the view dialect; retained for reference) |
| `host.js` | the handwritten JS host bridge (DOM writes + event forwarding) |
| `build.py` | expands string literals to byte-lists; bundles `app.html` + `bundle.glon` |
| `glon.wasm` | the WASM runtime (built by `make wasm-g1a`) |
| `node_test.js` | headless verification |

## Build

```
emcc            # Emscripten >= 3.1 (tested 3.1.74)
node            # for the headless test
make wasm-g1a   # builds glon.wasm + bundles app.html
```

`make wasm-g1a`:
1. compiles `standalone/glon.c` + `r0_s1_g1a.c` + `s1.c` + `r0_s1_runtime.c`
   to a raw `glon.wasm` (no libc, no WASI, no virtual filesystem);
2. runs `build.py`, which expands `"…"` string literals to byte-lists and
   combines `g1b.glon` + `shop.glon` into the bundled source.

## Launch

```
python3 -m http.server 8000
# open http://localhost:8000/demo/shop/app.html
```

## Manual acceptance

```
Open app → see "Glon Shop"
click "View products" → Products page appears, "Products page visits: 1"
click "Back home" → Home appears
click "View products" → "Products page visits: 2"
```

No page reload, and the network panel shows no fragment fetches.

make wasm-g1a-test
