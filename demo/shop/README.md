# Glon Shop — G1C (generic SPA application events)

G1A proved the persistent browser-hosted Glon/WASM machine; G1B layered a small
view dialect over it; G1C adds a generic browser→Glon application-event path.
See `../../GLON-SHOP-G1C.md` (and `GLON-SHOP-G1A.md` / `GLON-SHOP-G1B.md`).

| file | role |
|---|---|
| `app.html` | the bundled page (generated by `build.py`) |
| `bundle.glon` | the combined GLON source (generated by `build.py`; used by `node_test.js`) |
| `shop.glon` | the authoritative application (state, catalog, views, routes, events, router) |
| `g1b.glon` | the view-dialect library (emitters + view terms, incl. `button`) |
| `fragments/*.html` | G1A's HTML fragments (superseded by the view dialect; retained for reference) |
| `host.js` | the handwritten JS host bridge (DOM writes + route/event forwarding) |
| `build.py` | expands string literals to byte-lists; bundles `app.html` + `bundle.glon` |
| `glon.wasm` | the WASM runtime (built by `make wasm-g1a`) |
| `node_test.js` | headless verification |

## Build

```
emcc            # Emscripten >= 3.1 (tested 3.1.74)
node            # for the headless test
make wasm-g1a   # builds glon.wasm + bundles app.html
```

## Launch

```
python3 -m http.server 8000
# open http://localhost:8000/demo/shop/app.html
```

## Manual acceptance

```
Open app → see "Glon Shop"
click "View products" → Products page appears, "Products page visits: 1", "Cart: 0"
click "Add" → "Cart: 1"
click "Add" → "Cart: 2"
click "Back home" → Home appears
click "View products" → "Products page visits: 2", "Cart: 2" (persisted)
```

No page reload; navigation and events are both handled by the persistent Glon
machine, and JavaScript never interprets the `add-one` token.
