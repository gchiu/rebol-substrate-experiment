Glon

Glon is a small experimental programming language inspired by the Rebol family.

It runs interactively in WebAssembly, right in this browser. Code is made of blocks, words and values; functions are lexically bound closures; programs can run as cooperative tasks; and failures are first-class SIN! values that you raise and judge.

A first taste

Calls are prefix and take a fixed number of arguments, so no parentheses are needed:

double: func [x] [
    * x 2
]
double 21
;; => 42

What Glon has today

  • Blocks and words. A block is data until something evaluates it.
  • Lexical binding and closures. A function keeps the context it was made in; a block that depends on a call may not escape that call.
  • Cooperative tasks. spawn, yield and run-tasks interleave work deterministically.
  • SIN!, raise and judge. Creating a sin is harmless. Raising it causes trouble. Judgment permits execution to continue.
  • Executable laws. The language is developed against written laws and a native test suite, and the browser examples are tested too.
  • Real programs. The traffic simulator runs IDM, Newell, OVM/FVDM and NaSch models in Glon, in the browser.

Glon is a place for gloriously hacking both the code and the language. It is an experiment: expect sharp edges, and expect it to change.
